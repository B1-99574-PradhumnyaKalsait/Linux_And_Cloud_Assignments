Objective: To learn and practice the "cp & mv" commands in Linux.
Instructions:


Assignment 1 - Using the "cp" command:
1. Create a directory called "my_files" in your home directory.
        pradhumnya-kalsait@pradhumnya-kalsait-Latitude-5420:~/Desktop/Linux-Programming-Cloud_Computing/Assignment_to_push/Assignment5$ cd ~
        pradhumnya-kalsait@pradhumnya-kalsait-Latitude-5420:~$ mkdir -v myfiles
        mkdir: created directory 'myfiles'



2. Create three text files named "file1.txt", "file2.txt", and "file3.txt" in the "my_files"
directory. ( Use Command “touch” )
    pradhumnya-kalsait@pradhumnya-kalsait-Latitude-5420:~$ cd myfiles/
    pradhumnya-kalsait@pradhumnya-kalsait-Latitude-5420:~/myfiles$ touch file{1..5}.txt
    pradhumnya-kalsait@pradhumnya-kalsait-Latitude-5420:~/myfiles$ ls 
    file1.txt  file2.txt  file3.txt  file4.txt  file5.txt



3. Create a directory called "backup" in the "my_files" directory.
    pradhumnya-kalsait@pradhumnya-kalsait-Latitude-5420:~/myfiles$ mkdir -v backup
    mkdir: created directory 'backup'

4. Use the "cp" command to make a backup of "file1.txt" and "file2.txt" in the "backup"
directory.
    pradhumnya-kalsait@pradhumnya-kalsait-Latitude-5420:~/myfiles$ cp file1.txt file2.txt backup
    pradhumnya-kalsait@pradhumnya-kalsait-Latitude-5420:~/myfiles$ ls -lh backup/
    total 0
    -rw-rw-r-- 1 pradhumnya-kalsait pradhumnya-kalsait 0 Sep 11 15:24 file1.txt
    -rw-rw-r-- 1 pradhumnya-kalsait pradhumnya-kalsait 0 Sep 11 15:24 file2.txt
    pradhumnya-kalsait@pradhumnya-kalsait-Latitude-5420:~/myfiles$ 


5. Use the "cp" command to copy "file3.txt" to your desktop.
    pradhumnya-kalsait@pradhumnya-kalsait-Latitude-5420:~/myfiles$ cp file3.txt ~/Desktop

6. Copy “my_files” directory in home directory with the name “my_old_files”. ( Hint : -R )
